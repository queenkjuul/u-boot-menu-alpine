# Debian `u-boot-menu` scripts for Alpine Linux

I grew accustomed to the convenience of a single command to update my extlinux.conf with whatever kernels and device overlays I happened to have installed, and when I started building [Alpine images for the Milk-V Duo series](https://github.com/queenkjuul/milkv-duo-alpine) I found that these tools were Debian-specific, so I've forked the Debian package here and made some modification to run properly on Alpine, as well as APK packaging.
